# 别忘了_V1.0到V1.1_关键变化说明

> **性质：** 规格澄清升级，不扩V1功能范围。  
> **输入：** V1.0三份正式文件＋80问形成史＋Plus独立审核＋Pro独立审核＋守一最终裁决。  
> **原则：** 只吸收会减少实现歧义、虚假安心、数据失真、双端漂移和真实交付风险的高价值建议。

## 一、进入V1.1的核心变化

1. 增加产品信任三原则：不制造虚假安心、不静默改写事实、不静默丢数据。
2. 完成文案调整为“这份清单已全部处理，可以放心出发”，只陈述当前Run快照。
3. 重构Check Run状态机：仅`inProgress / completed / endedWithUnresolved / discarded`。
4. `reopened`改事件；`staleCandidate`改派生状态；`planned`归Planned Check；`deleted`归数据治理。
5. Planned Check创建时冻结完整模板快照，之后模板更新 / 删除不静默改变计划。
6. History采用“CheckRun唯一事实源＋append-only closedEvents＋只读投影”，不再建立第二个可变真相源。
7. 增加持久化失败合同：UI不能静默显示“已保存”。
8. 明确PWA持久存储只是额外保护，不能替代备份。
9. Backup Envelope增加`backupFormatVersion`，与`schemaVersion`分离。
10. schema升级增加旧client / 新schema并发写保护要求。
11. 明确V1双端默认不自动同步，是两个本地数据岛。
12. 分享区分官方模板、个人模板、本次结果；默认不外发oneTimeNote。
13. 三状态交互冻结：主点击只切`unchecked ↔ confirmed`，`notNeeded`独立次级动作。
14. 日期级计划不做UTC漂移；时间使用浮动本地墙上时间的最小方案。
15. 提醒改为L0应用内核心、L1系统日历优先增强、L2 Push / 订阅消息条件实现。
16. 首页“最相关Run”增加确定性规则。
17. 官方模板加入稳定Template ID / Item ID / contentVersion / condition / hint / searchAliases / featuredOrder。
18. checkbox按“一项一确认”重新审查，清理泛化或说明型项目。
19. 搜索别名成为正式内容资产。
20. 冻结7张首页精选模板。
21. 建立跨端领域行为合同和Golden Fixtures。
22. Codex执行顺序改为“能力尖峰 → 领域合同 → PWA纵切 → PWA全量 → 微信纵切 → 微信全量”。
23. 运行时禁止非必要远程字体、CDN、Analytics、广告SDK。
24. 验收升级为语义门、数据门、交互门、真实终端门。
25. “2周＋30次Run”只作为稳定性门，另加人工价值门。
26. 本地个性化保留能力但降为P2，不阻塞V1发布。

## 二、明确未吸收

为了避免把轻产品做成重治理项目，V1.1不加入：

- related templates联动；
- 复杂本地Analytics / 证据采集子系统；
- 七层信任模型作为七套正式制度；
- 账号、云同步、AI；
- 更多首发模板；
- 复杂国际日历 / 绝对时刻模型；
- 重型需求管理系统。

## 三、建议来源

### Plus独裁主要贡献

- 信任三原则；
- Check Run状态维度整理；
- stable ID；
- searchAliases；
- featuredOrder；
- 产品参数注册；
- Local-first持久性边界；
- backupFormatVersion；
- schema升级并发安全；
- 主源权威链；
- 运行时第三方依赖边界；
- 发布后价值门。

### Pro独裁主要贡献

- Planned Check快照；
- 完成语义范围边界；
- 持久化失败合同；
- 提醒能力梯度；
- checkbox原子性；
- condition字段；
- 分享隐私；
- 双端不自动同步事实；
- 三状态交互语法；
- 跨端可执行合规合同；
- 风险尖峰＋纵向切片开发顺序；
- 事实可信验收。

### 守一最终第三路径

1. History采用单一事实源，不采用第二个可变History真相源；
2. 时区不做重型调度，使用浮动本地日期 / 时间＋创建时区元数据；
3. 首页排序融合“计划紧迫性＋最近实际交互”；
4. 不吸收related templates、本地Analytics等聪明但非必要功能；
5. 完成文案用“这份清单已全部处理”，避免把`notNeeded`错误说成“全部已确认”。
