# 别忘了_官方模板内容库_V1.1

> **定位：** 「别忘了」V1.1首发官方模板唯一正式内容主源。  
> **内容版本：** Official Content V1  
> **首发数量：** 13张  
> **主源原则：** 本Markdown是人类可审阅主源；`contracts/official-templates.v1.1.json`是派生机器资产，若不一致，以本文件为准并重新生成JSON。  
> **内容原则：** 少而精｜高频＋高后果｜场景流优先｜关键项稀疏｜一项一确认｜条件与标题分离｜稳定ID与文案解耦。

## 一、内容身份规则

1. `templateId`、`groupId`、`itemId`正式发布后不得复用给其他对象；
2. 文案修改不自动更换ID；只有语义主体真正变成另一项时才创建新ID；
3. `contentVersion`描述官方内容版本，不等于数据库`schemaVersion`；
4. `condition`描述什么时候需要检查，不把条件句塞进title；
5. `hint`只放真正增加操作价值的短提示；
6. 一个checkbox原则上只代表一个可以独立确认的事实；互斥替代物、连续空间扫描或不可分割的信息包可以作为单项；
7. 官方模板只是通用高质量默认，不承诺穷尽现实场景；个人特殊事项通过本次临时项或个人模板处理。

## 二、关键项判定标准

优先标记为`key`，至少满足以下一项：

- 遗漏可能直接导致本次场景失败；
- 遗漏造成明显不可逆或高成本后果；
- 涉及身份、入境、核心工作资料或明确健康/安全需要；
- 到现场后通常难以低成本补救。

仅仅“最好带”“比较方便”“通常有用”不得标为关键项。

## 三、首页精选集合

1. `official.daily_out`｜日常出门
2. `official.important_errand`｜重要办事 / 会议出门
3. `official.domestic_travel`｜国内旅行
4. `official.hotel_checkout`｜离开酒店
5. `official.child_day_out`｜带娃出门
6. `official.away_from_home`｜离家数日
7. `official.important_medical_visit`｜重要就医

精选集合用于新用户首页“精选场景”；其余官方模板仍可通过浏览和搜索使用。

## 五、内容治理与发布前检查

每张官方模板发布 / 升级前至少完成：

1. 适用范围检查；
2. 一项一确认检查；
3. 关键项稀疏性检查；
4. 条件项是否已从title拆出；
5. 动作流 / 空间流是否自然；
6. 与相邻模板的结构性重复检查；
7. 真实场景口述走查；
8. 反向提问：模板外还可能漏掉什么高后果、通用、可检查事项；
9. 稳定ID、contentVersion、searchAliases、featuredOrder校验；
10. 高后果模板（出国旅行、带娃旅行、离家数日、住院准备、重要就医）至少进行一次独立第二视角校准。

## 六、明确不做

- 不因为“还能想到”就继续扩首发模板数量；
- 不建立飞机 / 高铁 / 自驾等复杂变体树；
- 不让Codex自行重写官方模板正文；
- 不把编辑意图直接展示给用户；
- 不把医疗模板扩展为医疗诊断或治疗建议。
